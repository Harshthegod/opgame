# Riftbound: Infinite Frontier

A lightweight, single-player browser prototype built with Canvas 2D. It includes
local battle practice against clearly labeled bots and an endless Rift Survival
mode. Online multiplayer and 3D rendering are not implemented.

## Run

Open `index.html` in a modern browser.

## Controls

- **WASD / arrow keys**: move
- **Shift**: sprint
- **Space**: dash toward your aim
- **Mouse**: aim and fire
- **E**: collect nearby resources
- **B**: place the selected structure at the pointer
- **1–4**: select wall, ramp, platform, or barrier

In Rift Survival, clear each wave to restore a little health and shield and earn
resources. Enemy count and durability increase over time; the safe zone does not
shrink in this mode.
